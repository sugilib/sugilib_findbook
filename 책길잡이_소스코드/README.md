# 책길잡이

영일고등학교 수기도서관의 진로·교과 연계 도서추천 서비스입니다. 진로 화면은 즉시 공개하고, 교과 화면은 서버에 저장된 공개 설정으로 제어합니다.

## Netlify 배포

1. 이 폴더를 Git 저장소에 올리고 Netlify에서 새 사이트로 연결합니다. 빌드는 `npm run build`, 게시 폴더는 `dist`, 함수 폴더는 `netlify/functions`입니다. `netlify.toml`에 설정되어 있습니다.
2. Netlify 사이트 환경변수에 `ADMIN_PASSWORD_HASH`, `SESSION_SECRET`을 설정합니다. 비밀번호 자체를 환경변수나 소스에 저장하지 마세요.
3. 로컬 터미널에서 `node -e "console.log(require('node:crypto').createHash('sha256').update(process.argv[1]).digest('hex'))" '원하는_관리자_비밀번호'`로 해시를 만들고 출력값을 `ADMIN_PASSWORD_HASH`에 넣습니다. `SESSION_SECRET`은 `node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))"`로 생성합니다. 값 설정 후 다시 배포합니다.
4. Netlify Blobs는 사이트 컨텍스트에서 영구 저장됩니다. 첫 요청 때 기본 분류와 교과가 생성되고, 이후 관리자 작업에서 저장됩니다. 초기 학과·도서는 실제 장서 자료에 맞게 관리자 화면에서 등록합니다. 운영 전에는 별도 백업 파일을 정기적으로 반출하세요.
5. 로컬 개발에서 Netlify 함수와 저장소를 사용하려면 Netlify CLI로 사이트를 연결하고 `netlify dev`를 실행해야 합니다. 단독 `npm run dev`는 프런트엔드 미리보기만 제공합니다.

## 관리자와 데이터

푸터의 ‘영일고등학교 수기도서관’을 클릭하면 관리자 로그인이 열립니다. 비밀번호는 서버 함수에서 검증하며 서명된 HttpOnly 쿠키로 8시간 세션을 유지합니다. 관리자 API는 매 요청마다 세션을 검사합니다. 사이트 설정에서 교과 도서를 공개하거나 다시 비공개로 돌릴 수 있습니다. 비공개 상태의 학생 요청에는 교과 데이터가 전달되지 않습니다.

도서는 한 레코드로 저장하고 진로 계열·학과·교과·세부 교과 연결을 별도로 저장합니다. 대표 추천 여부는 각 연결에 저장됩니다. 분류를 지우면 하위 분류 및 해당 연결 관계도 함께 삭제됩니다.

## Excel 등록과 반출

관리자 > Excel 일괄 등록에서 양식을 다운로드합니다. BOOKS 시트에 한 행당 한 권, 필수 항목인 도서명·저자·출판사·청구기호를 입력하세요. 분류명은 관리자 분류에 등록된 이름을 정확히 쓰고 복수 분류는 `|`로 나눕니다. 업로드 뒤 오류·중복을 확인하고 등록을 누릅니다. 주의 항목도 먼저 해결해야 등록 가능합니다. 일괄 등록은 한 요청당 최대 1,000권이며 모든 행의 검증이 끝난 뒤 저장합니다.

관리자 > 데이터 반출에서는 전체 또는 분류별 Excel을 다운로드합니다. 학과/세부 교과 상세에서도 현재 페이지와 연결된 도서를 내려받습니다.

## 현재 구현 범위

추천 테마 화면은 준비 안내이며 테마 관리 기능은 없습니다. 이용 통계는 수집하지 않습니다. 도서 표지는 외부 URL을 사용하므로 해당 사이트의 이미지 제공 정책에 따라 표시되지 않을 수 있습니다. 초기 41개 학과의 실제 소개·소장 도서 데이터는 제공되지 않아 임의로 채우지 않았습니다.
